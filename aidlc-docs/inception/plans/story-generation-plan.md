# 用户故事生成计划

## 目标

将已批准的游戏需求转化为以玩家旅程为中心、符合 INVEST 的用户故事、persona 和可测试验收标准。

## 推荐拆分方法

推荐采用**玩家旅程主导的混合方式**：以“进入游戏 → 过河 → 处理风险 → 完成/重玩”为主线组织史诗，并在每个故事中映射相应功能（3D、音效、无障碍和游戏状态）。这能保持玩家体验完整，同时使状态机、关卡和测试边界清晰。

可选方法比较：

- **玩家旅程**：最适合本游戏，清楚表达连续交互与状态反馈。
- **功能导向**：便于按技术模块实现，但会弱化完整的玩家体验。
- **Persona 导向**：当前只有一类核心玩家，单独采用价值较低。
- **领域导向**：适合复杂业务系统；对本单页游戏过重。
- **史诗导向**：将作为旅程方案的结构层级使用，而非唯一拆分方式。
