# 玩家 Persona

## Persona：轻松过河的网页玩家（小林）

### 概况

- **类型**：首次或偶尔游玩的休闲网页玩家。
- **使用环境**：笔记本浏览器、平板或手机浏览器；通常只有几分钟空闲时间。
- **动机**：无需学习复杂规则，快速获得“再跳一步就能到对岸”的紧张感和短时成就感。
- **行为特征**：先点击明显可达的木板；在失败后希望立即理解原因并一键再试；对分数和关卡提升有轻度兴趣。

### 需求与障碍

- 需要清楚的开始入口、极少的操作说明和足够大的触摸目标。
- 需要清晰看出哪些木板可跳、跳跃是否成功、生命是否减少、何时通关。
- 需要在 WebGL 或音频不可用时获得简洁说明，而不是技术错误信息。
- 需要可关闭音效，并且在窄屏上仍可阅读分数、生命和关卡。

### 成功定义

小林能在首次访问时开始游戏，通过点击理解“踩木板过河”的规则；每次掉水都得到明确反馈并可继续挑战；通关和重玩都立即、可靠且有成就感。

### 故事映射

- 核心：US-01 至 US-07。
- 关键可用性关注：US-01、US-02、US-06、US-07。
