## 覆盖总结

- 每一个用户故事均分配到至少一个主要单元，且跨边界行为均有支持单元与集成验证。
- **Security Baseline**：U2 承担静态运行时错误安全、外部依赖边界和资源清理；构建/测试阶段验证 HTTP 安全头、锁文件、扫描和 SBOM。U1 通过纯函数和无远程输入减少攻击面。
- **PBT**：U1 为 PBT-01、03、05、06、07、08、10 的主要责任单元；U2 为会话动作序列和资源释放的可观察集成边界。PBT-09（框架）在 U1 NFR 需求中确定。
