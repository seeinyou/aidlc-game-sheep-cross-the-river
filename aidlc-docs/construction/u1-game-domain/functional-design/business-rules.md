# U1 业务规则、验证与属性测试

## 业务规则

### 状态与动作验证

1. 有效阶段仅为 `ready`、`playing`、`jumping`、`level-complete`、`game-over`。
2. `START` 仅在 ready 改变游戏；`SELECT_PLATFORM` 仅在 playing 改变游戏；`RESTART`/`TOGGLE_MUTE` 在任意阶段可处理。
3. `TICK.elapsedMs` 必须是非负且不小于状态中已有时间；过期 tick 不得倒退运动、阶段或分数。
4. 不存在、后方、不可达或阶段不允许的平台选择不得扣生命、改变分数或创建 JumpState。
5. 跳跃只能有一个活动目标；跳跃中任何额外选择均不得覆盖目标。

### 关卡与运动学约束

1. 同一 `(levelNumber, baseSeed)` 产生相同 LevelDefinition；关卡编号不同可变更布局，但使用相同的难度上限规则。
2. 第 1 关不含风险分叉；第 2 关起最多一条分叉；任意关至少存在一条主路径到 goal。
3. 难度参数使用 `min(levelNumber, 8)`，不会超过第 8 关的上限。
4. 任意合法 `elapsedMs` 下，所有 `PlatformPose` 保持河面定义边界内。
5. 仅落地时刻的承载检查决定跳跃成功；跳跃途中经过目标不构成成功。

### 生命、得分和重置约束

1. 初始生命为 3，掉水将生命减一且下限为 0。
2. 成功跳跃加 10；通关加 100 加每条剩余生命 25；不存在负分、掉水扣分或重复结算。
3. 掉水保留当前关、种子、分数和静音状态；只重置小羊位置、活动跳跃与生命。
4. 重玩恢复第 1 关、基准种子、3 生命和 0 分；保留最高分与静音状态。
5. `highScore` 只能维持或上升，且永远非负。

### 受控失败与效果

1. 任意未知动作或非法输入均返回不变状态或安全 reject 效果；不能抛出未处理异常。
2. 效果类型、音效名称和反馈键都必须在领域白名单中；不能携带原始异常或任意用户文本。
3. U1 不访问网络、存储、DOM、时间源或音频接口；所有外部值通过动作输入。

## PBT-01：可测试性质识别

| 组件 | 性质类别 | 性质 | 测试方法 |
|---|---|---|---|
| LevelFactory | Invariant / Oracle | 生成关卡始终有一条主路径；`validateReachability(createLevel(n,s))` 为真。 | 用领域生成器生成关卡号/种子；将可达性验证器作为独立 oracle。 |
| LevelFactory | Determinism | 同一关卡号/种子重复生成结构相等。 | 成对调用比较规范化关卡结构。 |
| BoardKinematics | Range invariant | 任意有界平台和非负时间都产生位于河流范围内的姿态。 | 生成平台与时间，断言 x/z/承载边界。 |
| GameReducer | Stateful model / Invariant | 任意有效动作序列后，生命在 0–3、分数非负、阶段合法，且 jump 只在 jumping 存在。 | 以简化模型执行命令序列并逐步比较可观察状态。 |
| GameReducer | Oracle | reducer 的开始/重开/掉水/通关增量匹配简单参考评分模型。 | 生成受限命令序列，与纯参考模型比较。 |
| ScorePolicy | Range / Monotonicity | 合法奖励不为负；high score 为输入最大值。 | 生成非负分数/生命，断言范围和最大值。 |
| ViewModel projection | Referential transparency | 相同状态总产生相同视图模型，且不修改输入。 | 深冻结输入并重复调用比较结果。 |

### PBT-02：往返性质

N/A。首版没有持久化、编码或解析对；若以后加入本地存档，则必须为 encode/decode 加入往返测试。

### PBT-04：幂等性

暂定 N/A。没有把领域动作声明为幂等；`RESTART` 具有重置语义而非从同一完整状态开始的通用幂等承诺。若后续加入状态规范化函数，必须测试 `f(f(x)) = f(x)`。

## 生成器要求（PBT-07）

- 关卡号：正整数，重点覆盖 1、2、8、9 和合理上界。
- 种子：有符号 32 位整数，包含 0、最小/最大边界和值重复场景。
- 时间：非负、单调序列，覆盖 0、跳跃刚开始、跳跃结束前/恰好/之后和长时间。
- 领域动作序列：只生成符合当前模型阶段的开始、选择、tick、重玩和静音动作；同时单独生成非法选择验证安全拒绝。
- 平台：结构有效、唯一 ID、有限尺寸与受限漂移参数；生成器必须保留可达主路径，不使用无约束原始对象。

## 收缩、重现与互补测试

- 使用支持自动收缩和种子的 JavaScript PBT 框架；失败输出种子和最小反例。
- 每一项关键路径（开始、有效跳跃、掉水、通关、最后一命、重玩）均保留至少一个示例测试；PBT 不替代示例测试。
- 若 PBT 发现错误，其收缩最小反例应加入示例回归测试。
